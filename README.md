# Understanding Latent World Models through Simulator-Grounded Causal Interventions

Anonymous repository prepared for double-blind peer review.

This project studies causal representations in frozen latent world models using simulator-grounded counterfactual interventions and Distributed Alignment Search (DAS). The experiments examine counterfactual steering, rollout consistency, prediction-error estimation, and relationships with planning performance.
